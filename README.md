# Developer website (Peter Fam)

One site for all apps:
- `index.html` — "Apps by Peter Fam"
- `app-ads.txt` — AdMob's line; covers every app published with this AdMob account
- `froghop/` — Frog Hop home page and privacy policy

Add a folder per new app (copy `froghop/` and edit).

## Host on GitHub Pages
1. Create a **public** repository named exactly `YOUR-USERNAME.github.io`.
2. Upload the contents of this folder to it (not the folder itself).
3. The site appears at `https://YOUR-USERNAME.github.io/` within a few minutes.
   - Frog Hop privacy policy: `https://YOUR-USERNAME.github.io/froghop/privacy.html`
   - app-ads.txt: `https://YOUR-USERNAME.github.io/app-ads.txt`
4. Use `https://YOUR-USERNAME.github.io` as the developer website in both stores.
